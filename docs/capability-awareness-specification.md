# 能力自覚・他覚システム 新規実装仕様書

**作成日**: 2025年7月21日  
**ステータス**: 確定仕様（ユーザー承認済み）

## ⚠️ 重要な区別

**本システム**: 新規開発予定の能力自覚・他覚機能  
**既存RBAC**: 権限管理システム（既に実装完了、別システム）

## 確定仕様

### 1. 階層的管理システム
- **階層深度**: 制限なし（無制限階層）
- **権限粒度**: ツール利用権、メモリアクセス範囲、人格生成権
- **階層関係テーブル**: `persona_hierarchy`（Closure Table Pattern）

### 2. 能力自覚・他覚機能
- **自覚**: 各人格が自身の能力・制約・責務を理解
- **他覚**: 他の人格の能力を観察・評価
- **継承**: 親から子への能力継承（制限付き）

### 3. 会話能力階層
- **親→子会話**: 人格FunctionCall機能を使用
- **既存機能拡張**: 主LLM→各人格対話の拡張
- **機能呼び出し**: 親人格が子人格機能を呼び出し可能

### 4. 技術設計（実装手順）
- **Step 1**: `persona_hierarchy`テーブル追加（Closure Table）
- **Step 2**: 権限継承ロジック実装
- **Step 3**: 能力自覚・他覚機能実装
- **Step 4**: 親子間会話システム実装

## 開発方針

1. **既存システムとの非破壊的統合**
2. **段階的実装**（Step 1-4の順次実行）
3. **紛らわしい記載の排除**（仕様統一の維持）

## 注意事項

- 既存のRBACシステムとは別の新機能
- 混同を避けるため、文書・コメントで明確に区別
- 実装前に紛らわしい設計記載の修正を完了済み
